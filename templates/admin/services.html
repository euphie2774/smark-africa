This page exists because pausing works: a paused listing leaves the grid, the search index and the chatbot's provider list, which is the whole point of the button - and would otherwise also mean leaving the view of the only people able to review it. An admin acting on a complaint has a service *name*, not a position in a list, so this filters and searches rather than paginating. Removal is two stages and this page is the middle one. A provider who has served their last client asks to be let go; an admin confirms nothing is still owed to anybody; the provider then presses Delete themselves. So the Confirm button here grants clearance - it does not delete. What an admin cannot do is override. A client the platform can prove is outstanding - an unpaid order, a refund owed, a ticket for an event still ahead, a request open at the desk - blocks removal for both roles, and pausing stays the takedown: the listing becomes unreachable while every order, thread and payment record stays joinable. #} {% block title %}Service listings - {{ super() }}{% endblock %} {% block content %}
